# Filament Studio

## Goal
The goal of this project is to offer a simple but flexible theme builder for Filament.

## Status
The current status quo is a Laravel app with a Filament admin panel installed. The admin panel is solely used for demoing the theme.

There is a PoC for the theme editor at the home route.

## Tech Stack
- Laravel 12
- Vanilla JS
- TailwindCSS v4

## Agent Behaviour

- Always ask questions if something is unclear
- Use Playwright MCP to validate UI changes
- The project is accesible in the browser via https://tweakfilament.test
